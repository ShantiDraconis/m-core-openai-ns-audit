# BACKWARD_ORACLE_PROTOCOL

Status: GLOBAL FAIL-CLOSED POLICY

For every mathematical endpoint in this repository:

1. The final target must first exist as an explicit typed proposition/definition.
2. A hypothetical closure oracle is specification-only and must live in a dedicated module.
3. Independent frontier/reproduction files must not import or mention that oracle.
4. WITH_ORACLE may expose the exact required witness/output; WITHOUT_ORACLE must leave every unresolved mathematical input explicit.
5. If the endpoint is not yet typed, record TYPE_ENDPOINT_RESIDUE instead of inventing a surrogate theorem.
6. Conditional wiring compiling GREEN does not promote the open mathematics.
7. Do not create a new K/stage merely because an interface, oracle, or conditional composition compiles.

Global accounting for certification-bearing sources:
- sorry
- admit
- sorryAx
- axiom
- constant/constants used as mathematical hypotheses
- hidden placeholder wrappers
- EXTERNAL_CLASSICAL dependencies
- open hypotheses passed as theorem arguments
- #print axioms dependencies

Closed-target defaults:
SORRY_COUNT=0
ADMIT_COUNT=0
SORRYAX_COUNT=0
UNACCOUNTED_AXIOM_COUNT=0
UNACCOUNTED_CONSTANT_COUNT=0
UNRESOLVED_PLACEHOLDER_COUNT=0

A GREEN backward A/B test certifies the reduction/firewall only. It is not a proof of the endpoint.
